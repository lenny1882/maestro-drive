# Limits

Maestro Cloud applies a 20-minute soft limit per test execution. Break longer suites into smaller, parallelizable Flows.

Maestro Cloud applies a **soft limit of 20 minutes** per test execution.

{% hint style="warning" %}
After 20 minutes of execution, your test may be stopped at any time.
{% endhint %}

Ensure your Flows are optimized for speed and efficiency to stay within this limit. For longer test suites, consider breaking them into smaller, parallelizable Flows.
